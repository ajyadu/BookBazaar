# BookBazaar - Online Bookstore

BookBazaar is an online bookstore web application developed using Python and Django.
Users can browse books, register/login, add books to their cart, place orders, and
view their order history. The project also includes REST APIs for selected features.

## 🚀 Features

- User Registration and Login
- User Logout
- Browse available books
- Book details
- Search and filtering
- Add books to cart
- Update cart quantity
- Remove books from cart
- Checkout and place orders
- View order history
- View order details
- User profile
- Admin panel for managing books and orders
- REST API for order/cart functionality

## 🛠️ Technologies Used

- Python
- Django
- Django REST Framework
- MySQL
- HTML5
- CSS3
- JavaScript
- Bootstrap
